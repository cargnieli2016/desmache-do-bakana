# Desmanche do Bakana

Site institucional do Desmanche do Bakana, com catálogo de veículos, contato pelo WhatsApp e mapa de localização.

## Tecnologias utilizadas

Este site foi desenvolvido com:

- React
- Vite
- TypeScript
- Tailwind CSS
- TanStack Router
- TanStack React Query
- GitHub Pages para publicação

## Desenvolvimento local

Requisitos: Node.js e npm.

```sh
npm install
npm run dev
```

## Sobre o projeto

O site apresenta o Desmanche do Bakana e facilita o acesso às principais informações para os clientes. A experiência reúne o catálogo de veículos, o contato direto pelo WhatsApp e a localização da empresa em um só lugar.
